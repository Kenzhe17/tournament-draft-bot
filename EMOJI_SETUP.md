# Настройка кастомных эмодзи для рангов

## 📋 Как получить ID эмодзи из Discord

### Способ 1: Через Discord клиент
1. Напишите сообщение с эмодзи (добавьте пробел перед и после)
2. Нажмите на эмодзи в сообщении правой кнопкой мыши
3. Выберите "Copy ID" (Копировать ID)
4. ID будет скопирован в буфер обмена

### Способ 2: Через URL
1. Откройте настройки сервера → Emoji
2. Нажмите на нужный эмодзи
3. В URL будет виден ID: `https://discord.com/channels/123456789/emoji/123456789012345678`
4. Последнее число и есть ID эмодзи

### Способ 3: Через режим разработчика
1. Включите Developer Mode в Discord (Settings → Advanced → Developer Mode)
2. Нажмите правой кнопкой на эмодзи в списке эмодзи сервера
3. Выберите "Copy ID"

## 🔧 Настройка в Railway

### 1. Загрузите эмодзи на сервер
1. Откройте настройки сервера → Emoji
2. Загрузите эмодзи из папки `C:\Users\2006k\Downloads\emoji-ranks`:
   - Radiant.png
   - Immortal.png
   - Ascendant.png
   - Diamond.png
   - Platinum.png
   - Gold.png
   - Silver.png
   - Bronze.png

### 2. Получите ID эмодзи
Используйте один из способов выше для каждого эмодзи

### 3. Добавьте переменные окружения в Railway
1. Откройте ваш проект на Railway
2. Перейдите в Settings → Variables
3. Добавьте следующие переменные (используйте ТОЛЬКО ID без каких-либо префиксов):

```
EMOJI_RADIANT=123456789012345678
EMOJI_IMMORTAL=123456789012345679
EMOJI_ASCENDANT=123456789012345680
EMOJI_DIAMOND=123456789012345681
EMOJI_PLATINUM=123456789012345682
EMOJI_GOLD=123456789012345683
EMOJI_SILVER=123456789012345684
EMOJI_BRONZE=123456789012345685
```

**ВАЖНО:**
- Замените числа на реальные ID ваших эмодзи
- ID должен быть только число (например: 123456789012345678)
- НЕ добавляйте префиксы <:Name:> или :Name:
- НЕ добавляйте кавычки или другие символы

### 4. Перезапустите проект
После добавления переменных перезапустите проект на Railway.

## 🎯 Локальная настройка (для тестирования)

Для локального тестирования добавьте те же переменные в ваш `.env` файл:

```env
EMOJI_RADIANT=123456789012345678
EMOJI_IMMORTAL=123456789012345679
EMOJI_ASCENDANT=123456789012345680
EMOJI_DIAMOND=123456789012345681
EMOJI_PLATINUM=123456789012345682
EMOJI_GOLD=123456789012345683
EMOJI_SILVER=123456789012345684
EMOJI_BRONZE=123456789012345685
```

## ⚠️ Важно

- Эмодзи должны быть загружены **на тот же сервер**, где работает бот
- Если эмодзи не будут найдены, система будет использовать текстовые названия
- ID эмодзи - это числа, не используйте в них пробелы или другие символы
- После настройки перезапустите бота для применения изменений

## 🔍 Проверка

После настройки:
1. Используйте команду `/rank` для проверки отображения эмодзи
2. Откройте `/welcome` → "Система прогрессии, уровни и ELO" для проверки гайда
3. Если эмодзи не отображаются, проверьте правильность ID в переменных окружения
