# Эмодзи r!z3 Assets 2.0 — карта соответствия и инструкция по загрузке

Источник: `rize3_assets_v2_complete/emojis/` → скопировано в `assets/emojis/`
(30 файлов, 128×128 PNG, RGB, без текста — Discord принимает как emoji).

## Как это подключается

1. Загрузите PNG на Discord-сервер (**Server Settings → Emoji → Upload**).
   Имя эмодзи = имя файла без `.png` (`coins`, `wallet`, …) — либо переименуйте
   при загрузке под нужный ключ.
2. Пропишите ID в `utils/design/emojis.py` → `EMOJI_IDS`:
   - `"ключ": "1234567890123456789"` — если имя эмодзи совпадает с ключом;
   - `"ключ": "discord_name:1234567890123456789"` — если имя отличается
     (например `"coin": "coins:123…"` для `coins.png`).
3. Пока ID пуст — работает unicode-fallback из `FALLBACKS`, ничего не ломается.
4. Также можно задать `EMOJI_<KEY>` env-переменные (см. `config.py` /
   `EMOJI_SETUP.md`) — `em()` проверяет `EMOJI_IDS` первым, затем config.

Старые эмодзи с сервера **не удаляются**: новые просто заменяют визуал
там, где указан ID. Лимит слотов сервера не превышать — загружайте
только нужные файлы.

Примечания:

- «Новый» ключ = добавлен в `EMOJI_IDS`/`FALLBACKS` в этом обновлении;
  до загрузки эмодзи работает unicode-fallback.

  продублируйте ID в `EMOJI_IDS` под оба ключа.

  ближайшие семантические ключи; при желании можно завести отдельные ключи.
