# CODEX_HANDOFF.md — передача проекта OpenAI Codex

## Краткое описание

Discord-бот **r!z3** — платформа турниров и мини-игр для одного сервера: турниры 8/16/32 (команды по 4, драфт ELO/SKILL/RANDOM), Battle Royale, Ultimatum, матчмейкинг, ставки, OCR результатов матчей (RapidOCR), Free Fire API, экономика/магазин/питомцы, ~40 мини-игр, профили/репутация/брак/ДР. Python 3.12 + discord.py 2.7 + Components V2, PostgreSQL (asyncpg) + JSON-сторы, деплой Railway.

## Git-состояние

- Репозиторий: https://github.com/Kenzhe17/tournament-draft-bot
- Production-ветка: `main` (последний коммит `7ce77ce`).
- Эта документация подготовлена в ветке **`handoff/codex-migration`** — она ответвлена от `main` и содержит только доки + санитизацию `.env.example`. Игровая логика не менялась.
- Незакоммиченных изменений кода нет; все рабочие изменения уже в `main`.

## Что разработано и работает

См. `docs/FEATURES.md` — всё подтверждено кодом: турниры/драфт/сетка/комнаты/OCR/ставки/ELO/XP, BR (3+ карт), ultimatum, `/mm`, `/ff`, `/statistic`, питомцы/магазин/гардероб/кейсы, экономика, ~40 мини-игр, профили/`/rep`/брак/ДР, модерация, Components V2 UI.

## В процессе / незавершено

- **Team Preview (CS-style картинка)** — обсуждено, **не реализовано**, ждёт шаблон от пользователя.
- Диагностика кнопок в `/tournament create` — временная, убрать после подтверждения на проде.
- OCR: ручное сопоставление ников; авто-матчинг не сделан.

## Следующие шаги (приоритет)

2. Параметризовать захардкоженные ID каналов/ролей (env).
3. Team Preview после получения шаблона.
4. Тесты на критические пути (ELO, `process_match_result`, экономика).

## Технические риски

1. **Секреты в истории git** — `DISCORD_TOKEN` был закоммичен в `.env.example`; `MOD_LOG_WEBHOOK_URL` с реальным webhook — дефолт в `config.py`. Оба нужно ротировать и убрать.
2. **Нет автотестов** — регрессии ловятся только вручную/на проде.
3. **Двойное хранение**: PG + JSON; JSON без транзакций и без volume теряется.
4. **Магические ID** — привязка к одному Discord-серверу.
5. **CV2-адаптер** — хрупкое место: Discord меняет Components V2; в `views/br_view.py` ~4000 строк с дублированием.
6. **Free Fire API** — сторонний сервис, 403 на части эндпоинтов.
7. **OCR** — RapidOCR/ONNX, чувствителен к версии игры/скриншотов.
