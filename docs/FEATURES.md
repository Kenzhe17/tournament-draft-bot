# FEATURES.md — реализованные функции r!z3

## Турниры (`/tournament` + группы)

- Размеры 8/16/32 игрока → команды по 4 → сетка: 8=1 матч, 16=полуфинал, 32=отбор+полуфинал+финал.
- Режимы формирования: **Manual** (драфт по кругам), **ELO**, **SKILL**, **RANDOM** (авто-драфт).
- Регистрация, изоляция, оргроли (`ORG_1..3_ROLE_ID`), орг-меню, удаление турнира.
- Комнаты матчей: кнопка на матч → модалка ID/пароль → единая V2-карточка «КОМНАТА ОТКРЫТА» (`Матч: капитан vs капитан`, строки `num_X <@…>`, ID+пароль) в канал данных + анонс «Комната открыта, данные» в общий канал.
- OCR результатов: кнопка «📸 Скриншот» → RapidOCR (CS 4x4, 2-панельный и squad-режим) → сообщение в `1568608461250367569` с ручным сопоставлением ников (капитан — только своя команда, орг — любая), авто-победитель по подсветке/баннеру, «Неправильный скриншот», «Вызвать организатора».
- Итоги: карточка «ИТОГ МАТЧА» в `1568290145138900992` (команды=имена капитанов, составы ментионами, скриншот; обновляется при перезаливе).
- Ставки: динамические коэффициенты (`match_odds`), окно 3 мин, расчёт при завершении.
- ELO: перфоманс-модификатор относительно всех 8 игроков (±5/±3/0/−3/−5), без бонусов питомцев, округление один раз; XP/уровни/монеты за матчи; `match_history`, лидерборды.
- Профиль: `/player profile` (био под заголовком, аватар, супруг, репутация, ДР), настройки (ДР/ник/описание, кулдаун 7 дней на ДР и описание), `/player history`, ранг.
- `/rep` — +1 репутация, 1 раз на пару навсегда, лимит 3/день.
- Брак: `/player marry` (предложение 5 мин, кнопки принять/отклонить) + `/player divorce`; `spouse_id` в профиле.
- `/birthdays` — список ДР сервера, 5/стр, сортировка по ближайшим; авто-поздравление в 00:00 Asia/Almaty в `NOTIFICATION_CHANNEL_ID` (1200125075156910181); `/birthdaytest`.

## Battle Royale (`/br`)

- `/br create` — BR-турнир: random (20–48 игроков) или team-формат (зарегистрированные команды из `team_store`, мин. 5 команд по 4).
- До 12 команд; капитаны переименовывают команды (1 минута); роль `BR_ROLE_ID`.
- Карты: Бермуды → Чистилище → Калахари (`map_count` 1–10, цикл); очки = место {12,9,8,7,6,5,4,3,2,1,0,0} + убийства.
- Статистика вводится организатором по группам команд (модалки место/киллы), авто-переход фаз, финальные результаты.
- Комната: `BRRoomModal` → кнопка «Данные» → карточка «КОМНАТА ОТКРЫТА» со всеми командами (`num_X <@…>`) + ID/пароль в `1563195265395982466`; анонс с командами и пингом роли в общий канал.

## Ultimatum (`/ultimatum`)

Отдельная система в `ultimatum/`: модели, store, свой ELO (`elo_calculator`, `elo_store`), matchmaking, setup/result views, комната (`ultimatum_room_modal`).

## Matchmaking (`/mm`)

Поиск тиммейтов: `mm_search_store`, `views/mm_search_view`, уведомления в `NOTIFICATION_CHANNEL_ID`.

## Free Fire (`/ff`)

`/ff info|stats|ban|banner|wishlist` через siambhau FreeFireApi (`FREEFIRE_API_KEY`, регион CIS/RU default). `/ff ban` — premium-скрытие после 403. Каталог `ff_catalog`.

## Статистика FF (`/statistic`)

Скриншоты статистики CS 4x4 из папки → RapidOCR → таблица; маппинг Discord ID, контролы в канале `1568608461250367569`.

## Экономика и магазин

- Баланс/банк (`/economy`), переводы, кража (`/crime`), продажа, `coin_drop` (дейли).
- Магазин косметики (тэги/иконки), инвентарь, гардероб (`/wardrobe`), кейсы (`case_store`, `case_history`), раритеты/цвета.
