# Tournament Draft Bot

Discord-бот для проведения турниров с драфтом команд, системой ставок, магазином косметики и статистикой игроков.

## 🎮 Возможности

### Турниры
- **Размеры:** Турниры на 8, 16 и 32 игрока
- **Режимы формирования:**
  - **Manual:** Ручное распределение игроков по кругам
  - **ELO:** Автоматическое распределение по ELO-рейтингу
  - **Random:** Случайное распределение с автоматическим драфтом
- **Фазы:** Регистрация → Драфт → Квалификации → Полуфиналы → Финал
- **Комнаты:** Автоматическое заполнение комнат с DM-уведомлениями

### Статистика и ELO
- **ELO-рейтинг:** Динамическая система с множителями для топ-игроков
- **K/D:** Соотношение убийств к смертям с бонусами
- **Лидерборды:** Рейтинг по ELO и монетам
- **Профили:** Детальная статистика с аватарами и био

### Экономика
- **Монеты:** Валюта для ставок и покупок
- **Ставки:** Система ставок на матчи с выплатами
- **Магазин:** Косметические товары (тэги, иконки)
- **Награды:** Монеты за участие, победы и серию побед

### Интерфейс
- **Embed-сообщения:** Вся информация в одном месте
- **Кнопки:** Интуитивное управление турниром
- **Модальные окна:** Удобный ввод данных
- **Мобильная адаптация:** Компактный режим для мобильных устройств

## 📋 Требования

- Python 3.12+
- discord.py 2.x
- PostgreSQL (опционально, для базы данных)

## 🚀 Установка

```bash
cd tournament-draft-bot
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux/Mac
source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env
```

Укажите токен бота в `.env`:

```
DISCORD_TOKEN=your_bot_token_here
DATABASE_URL=postgresql://user:password@host:port/dbname  # опционально
```

### Настройка бота в Discord Developer Portal

1. Создайте приложение на [Discord Developer Portal](https://discord.com/developers/applications)
2. В разделе **Bot** скопируйте токен
3. Включите **Privileged Gateway Intents**:
   - Server Members Intent
   - Message Content Intent
4. Пригласите бота на сервер с правами:
   - `applications.commands`
   - `Send Messages`
   - `Read Messages/View Channels`

## 🎯 Команды

### Турнир

| Команда | Описание |
|---------|----------|
| `/tournament create` | Создать турнир (8/16/32 игроков, режим: manual/elo/random) |
| `/tournament delete` | Удалить активный турнир |
| `/test` | Заполнить турнир тестовыми данными (админ/org) |

### Статистика

| Команда | Описание |
|---------|----------|
| `/leaderboard` | Таблица лидеров по ELO |
| `/coins` | Таблица лидеров по монетам |
| `/profile` | Профиль игрока |
| `/setbio` | Установить био профиля |
| `/setavatar` | Установить аватар профиля |
| `/reset_leaderboard` | Сбросить статистику (админ/org) |

### Экономика

| Команда | Описание |
|---------|----------|
| `/shop` | Магазин косметики |
| `/inventory` | Инвентарь игрока |
| `/equip` | Экипировать предмет |
| `/balance` | Баланс игрока |
| `/bet` | Сделать ставку на матч |

### Админ-команды

| Команда | Описание |
|---------|----------|
| `!elo @player 1000` | Установить ELO игрока |
| `!coins @player 1000` | Установить монеты игрока |

**Примечание:** Админ-команды доступны **администраторам** сервера и игрокам с ролью **org**.

## 🔄 Режимы формирования

### Manual
- Игроки сами выбирают круг при регистрации
- Админы могут добавлять игроков вручную
- Возможность распределения по ELO перед стартом

### ELO
- Автоматическое распределение по ELO-рейтингу
- Игроки распределяются равномерно по командам
- Идеально для сбалансированных турниров

### Random
- Все игроки в одном пуле
- Автоматическое случайное распределение по командам
- Случайные капитаны и автоматический драфт

## 📊 Система ELO

### Базовое изменение
- Победа: +10
- Поражение: -10

### K/D бонус
- Формула: (убийства × 2) - смерти
- Топ 1-7 не получают K/D бонус при поражении

### Множители по месту в лидерборде (победа)
- 1-3 место: 0.4x (40%)
- 4-6 место: 0.6x (60%)
- 7-10 место: 0.8x (80%)
- Остальные: 1.2x (120%)

### Множители потерь по месту в лидерборде (поражение)
- 1-3 место: 2.0x (200%)
- 4-6 место: 1.5x (150%)
- 7-10 место: 1.3x (130%)
- Остальные: 1.0x (100%)

### Инверсия множителя
- Если при поражении итог положительный, множитель инвертируется (1.5x → 0.67x)

## 🏠 Система комнат

- **Заполнение:** Игроки команд и админы/org могут заполнять комнаты
- **DM-уведомления:** При заполнении комнаты всем игрокам отправляется DM
- **Формат DM:**
  ```
  @Player Комната вашей игры открыта!
  
  Игра: Team A VS Team B
  ID: `1234`
  Пароль: `secret`
  ```

## 🗑️ Управление игроками

### Кнопки (период регистрации)
- **🗑️ Удалить:** Удалить игрока из турнира (org только)
- **🔄 Заменить:** Заменить игрока (org только)
  1. Выбор из списка зарегистрированных игроков
  2. Ввод @упоминания нового игрока

## 📜 Логирование

Бот отправляет логи в Discord канал для отслеживания активности:

- Добавление бота на сервер
- Создание турнира
- Завершение турнира
- Ошибки команд

## 💎 Магазин косметики

### Товары
- **Тэги:** Цветные префиксы перед именем
- **Иконы:** Эмодзи рядом с именем
- **Редкость:** Basic, Premium, Elite, Special

### Управление
- `/shop` - Просмотр товаров
- `/inventory` - Инвентарь игрока
- `/equip` - Экипировать предмет

## 🔐 Права доступа

### Роль org
Игроки с ролью **org** имеют те же права, что и администраторы:
- Заполнение комнат
- Управление игроками
- Админ-команды
- Сброс лидерборда
