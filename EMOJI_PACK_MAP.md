# Карта эмодзи Minimal Dark UI

Паки лежат в `C:\Users\2006k\Downloads\emojies\` (3 папки .emojigg-pack).
Число в имени файла — ID эмодзи у emojigg, **не работает** на вашем сервере.
Загрузите нужные PNG на свой Discord-сервер как кастомные эмодзи,
скопируйте их ID (Developer Mode → ПКМ по эмодзи → Copy ID)
и впишите в переменные `EMOJI_*` (Railway Variables / .env).

До установки ID все эмодзи автоматически используют unicode-фолбэк.
